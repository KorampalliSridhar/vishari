## ❓ Frequently Asked Questions

### Q: What files do I need to deploy?
**A:** You need:
- `index.html`
- `styles.css`
- `script.js`
- `assets/` folder (with all images)

Documentation files (*.md) are optional for deployment.

### Q: Can I change the colors?
**A:** Yes! Edit `styles.css` and search for color codes like `#ff4757`. Replace with your desired colors.

### Q: How do I add my photo?
**A:** Replace `assets/profile.jpg` with your photo. Make sure it's named the same or update the path in `index.html`.

### Q: Will it work on mobile?
**A:** Yes! The site is fully responsive and works on all device sizes.

### Q: Do I need to know coding?
**A:** Basic HTML knowledge helps for content updates, but you can edit text content without deep technical knowledge.

### Q: Can I add more sections?
**A:** Yes! Edit `script.js` to add more tabs and content. Follow the existing pattern.

### Q: Is it free to deploy?
**A:** Yes! GitHub Pages, Netlify, and Vercel all offer free hosting for static websites.

### Q: How do I update content?
**A:** Edit `index.html` to change text, links, and personal information. See README.md for detailed instructions.
