## 🎨 Design Elements

### Color Scheme
- **Primary**: #FF4757 (Red/Pink accent)
- **Text**: #2C3E50 (Dark gray)
- **Background**: #F8F9FA (Light gray)

**To change**: Edit `:root` section in `styles.css`

### Typography
- **Font**: Inter (Google Fonts)
- **Sizes**: 28px → 14px (responsive)

**To change**: Edit font link in `index.html` and font-family in `styles.css`

### Layout
- **Desktop**: Two-column (sidebar + content)
- **Mobile**: Single column (stacked)

**To change**: Edit `.container` in `styles.css`

## 💡 Pro Tips

### Quick Edits
- **Colors**: Only edit `:root` section in `styles.css`
- **Content**: All text is in `index.html`
- **Functionality**: JavaScript is minimal and commented

### Before You Start
1. Make a backup copy of original files
2. Read `GETTING_STARTED.md` first
3. Start with small changes
4. Test in browser after each change
5. Use browser DevTools (F12) to debug

### Testing
- Press F12 in browser for DevTools
- Press Ctrl+Shift+M for mobile view
- Test on real devices when possible
- Check all tabs and links

## 🆘 Help & Support

### File-Specific Help

**Having trouble with HTML?**
- See `index.html` comments
- Check `GETTING_STARTED.md` for content updates

**CSS not working?**
- Ensure file is in same folder as `index.html`
- Check `GETTING_STARTED.md` troubleshooting section
- See `styles.css` comments for explanations

**JavaScript not working?**
- Check browser console (F12)
- Ensure `script.js` is in same folder
- See `script.js` comments

**Responsive design issues?**
- Read `RESPONSIVE_GUIDE.md`
- Check media queries in `styles.css`
- Test at actual breakpoints: 1024px, 768px, 480px
